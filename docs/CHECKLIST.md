# 验收清单

本项目**没有 UI 自动化测试**,所有验证都靠真机手动走。这份清单的作用是:改完东西照着走一遍,
不用每次临时想"该测什么"。

用法:改了哪块就走哪块的清单;涉及共用代码(提词器/电话拦截/定位修改/液态玻璃)时,**两个版本
都要走一遍**。发现新的失效方式就往对应小节补一条——清单靠积累才有价值。

---

## 0. 每次装机后必做(2 分钟,先于一切功能测试)

这几条是"地基",不过就别往下测了。

- [ ] **应用能启动,不闪退**(公开版尤其重要:GKD 内核删得很深,`App.kt` 启动流程被裁剪过)
- [ ] 启动页卡片数量正确:私人版 **5 张**,公开版 **3 张**
- [ ] 应用名正确:私人版 `癸月`,公开版 `癸月科技`(桌面图标下方 + 系统设置里的应用列表)
- [ ] 底部版本行显示正常,点开「关于」浮层不崩
- [ ] 「关于」里的版本类型/版本号/开发者对得上
- [ ] **公开版的使用说明里不该出现"去广告"和"虚拟定位"**
- [ ] 从每张卡片进去再返回,不崩、不卡在黑屏

## 1. 升级安装(改了数据结构/换了库/动了 applicationId 时必测)

- [ ] **覆盖安装后,原有提词器文稿还在**(这是最容易丢的数据,只存在手机本地)
- [ ] 玻璃预设、背景设置、电话拦截规则都还在
- [ ] 打开一篇**旧文稿**,格式没跑样:字号、行距、对齐、加粗都跟升级前一致
- [ ] 编辑旧文稿并保存,退出重进,改动还在且格式没退化

> 换富文本库(`richeditor-compose`)时这一节**优先级高于功能测试**——库升级会改 HTML 解析行为,
> 而本项目文稿是 Word→OOXML→HTML 导入的,带两端对齐和逐段字号,是高风险区。

## 2. 提词器(改动最多,bug 最集中)

**编辑页**
- [ ] 点正文任意位置,光标落在点击处(不是跳到末尾)
- [ ] 打字正常,退出重进内容还在
- [ ] **长按选中文字,拖动前后两个手柄:跟手、方向正确、不乱跳**(历史重灾区)
- [ ] 工具栏加粗/斜体/下划线/字号/对齐,作用在选中范围上
- [ ] 章节合并/拆分/升降级后,滚动位置没有乱跳到别处
- [ ] 大纲:点击跳章正确;长按拖动能连续翻章
- [ ] 系统返回键行为正确(不是直接退出整个页面)

**设置面板**
- [ ] 字号/整体缩放/行距/内容宽度:拖动时正文**实时跟着变**(不是松手才变)
- [ ] 拖动过程中屏幕外章节会延后重排,松手后**全文一致**,没有残留旧排版
- [ ] 副标题字号/加粗/颜色生效
- [ ] 播放页配色改了之后,进播放页确实生效
- [ ] 「恢复默认配色」能从白底白字这种撞色状态救回来
- [ ] 面板透明度/模糊度拖动生效,松手后停在最终值

**播放页**
- [ ] 滚动流畅,速度调节生效
- [ ] 横竖屏切换正常,内容宽度按各自设置走
- [ ] 控制栏能正常收起/展开

**导入导出**
- [ ] 导入 Word:标题层级识别正确,字号行距对齐保留
- [ ] 导出 Word:能被 Word/WPS 正常打开,格式没丢

## 3. 电话拦截

- [ ] 首次进入能正常申请「来电筛选」权限
- [ ] 黑名单模式:命中前缀的来电被拦截(不响铃),其余正常接通
- [ ] 白名单模式:只有命中前缀的能打进来,其余全部拦截
- [ ] **切换模式后,两边的前缀列表互不污染**
- [ ] 规则增删即时生效,重启应用后规则还在
- [ ] 子页面(规则管理/诊断日志)按系统返回键回到上一屏,不是直接退出整个功能
- [ ] 被拦截的来电仍留在系统通话记录里(**这是期望行为,不是 bug**)

## 4. 定位修改

- [ ] 能选到照片/视频文件
- [ ] 地图正常显示(用的是高德瓦片),能选点
- [ ] 保存后,用其它看图工具查看该文件,GPS 信息确实变了
- [ ] 原始文件没被损坏(还能正常打开)

## 5. 虚拟定位(**仅私人版**)

- [ ] 系统设置 → 开发者选项 → 选择模拟位置信息应用,列表里**能看到本应用**
- [ ] 选点开启后,地图类 App(高德等)显示的是模拟位置
- [ ] 持续跑几分钟,观察电量/CPU 没有异常升高(刷新间隔是 100ms,比默认激进)
- [ ] 关闭后定位恢复真实位置

## 6. 液态玻璃(改了 `glassui/`/`glasstuning/` 时)

- [ ] 各面板玻璃效果正常,**没有彩色条纹/花屏**(色散越界的典型症状)
- [ ] 拖动调参滑块,效果实时变化;**松手后停在最终值**,不是弹回
- [ ] 应用预设、恢复默认——全程无拖动手势,画面也要立刻反映新值
- [ ] 液态开关拖动跟手、不回弹;单击也能切换
- [ ] 各屏幕的玻璃参数**互不影响**(文档库/编辑页/播放页/启动页各自独立)
- [ ] 预设列表不串场景(在提词器存的预设,不该出现在启动页的列表里)
- [ ] 背景四种模式(默认/纯色/渐变/图片)都正常;图片模式的亮度/对比度/饱和度/模糊/透明度逐个生效
- [ ] 深色/浅色主题下都看得清

## 7. 两个工程一致性(改了共用代码后)

- [ ] 在**私人版**改的代码
- [ ] 跑过 `bash sync-to-public.sh`(先 dry-run 看清单,再 `--apply`)
- [ ] **公开版编译通过**
- [ ] 两个版本都装机走过第 0 节
- [ ] 如果本次从公开版删了什么功能,对应文件已补进脚本的 `NEVER_COPY`

## 8. 发布前(出正式包给别人用)

- [ ] `aapt2 dump badging` 核对:应用名、包名、版本号、**权限清单**
- [ ] 公开版权限应为 7 项左右,**不含**模拟位置/修改安全设置/读取已安装应用
- [ ] 解包 dex 核对被删功能确实不在里面(方法见 `DECISIONS.md` 2026-08-20)
- [ ] 在一台**没装过**本应用的手机上全新安装,走一遍第 0 节
- [ ] 已做 git commit + bundle 备份,并且备份**拷到了 F 盘以外的地方**
